# PROFLAUNDRY Platform

Универсальная веб-платформа для управления бизнесом — аналог 1С:Предприятие в браузере.

<!-- locked:start -->
## Концепция

Платформа предоставляет организациям инструменты для ведения бизнеса: справочники, документы, регистры — по модели 1С, но через веб-интерфейс без установки.

Система многоарендная (multi-tenant): несколько независимых организаций работают в одной системе, каждая в полностью изолированном пространстве данных.

## Три уровня доступа

| Уровень | Кто | URL | Что видит |
|---------|-----|-----|-----------|
| **Платформа** | Администраторы платформы | `/platform/` | Все организации, все данные |
| **Организация** | Сотрудники организации | `/app/` | Только данные своей организации |
| **Клиент** | Клиенты организации | `/portal/` | Только свои данные (заказы, счета, история) |

Каждый уровень имеет отдельный интерфейс входа и изолированный набор экранов.
